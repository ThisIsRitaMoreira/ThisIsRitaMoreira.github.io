# `data/attrition.js` — schema

Generated by `analysis/people_attrition.R`; do not edit by hand.

```
Rscript analysis/people_attrition.R <ibm_attrition.csv> data
```

The file sets one global: `window.DATA_ATTRITION = {...};`

Conventions

* **Rates and probabilities** are proportions between 0 and 1, rounded to 4 decimals (`0.1612` = 16.1%).
* **p-values** have 3 significant figures (`3.86e-21`). Odds and hazard ratios have 3 decimals.
* **Counts** are integers. A missing or not-estimable value is `null`.
* **Text** may contain an en dash, ≥, ≤, → or ×. These are written as `\uXXXX` escapes, so the file is pure ASCII.
* **Arrays of objects** are row-wise (`[{...}, {...}]`). The one exception is `whatif.employees`, which is columnar.
* **Data:** IBM's fictional HR attrition sample (1,470 employees). Every page that shows it should say the data is fictional.

Top-level keys: `meta`, `overview`, `segments`, `logit`, `survival`, `tree`, `whatif`, `insights`, `recommendations`, `caveats`.

## `segments`

Baseline attrition by group.

* `note` (string): ordering rules.
* `variables` (array, 14 items, strongest association first by Cramér's V). Each item:

| Field | Type | Meaning |
|---|---|---|
| `key` | string | Stable id: `OverTime`, `JobRole`, `TenureBand`, `JobLevel`, `AgeBand`, `IncomeBand`, `StockOptionLevel`, `MaritalStatus`, `BusinessTravel`, `EnvironmentSatisfaction`, `JobSatisfaction`, `WorkLifeBalance`, `DistanceBand`, `Department` |
| `label` | string | Display name ("Years at company", "Monthly income (quartile)", ...) |
| `kind` | string | `"ordinal"`: levels are in natural order. `"nominal"`: levels are sorted by rate, highest first |
| `chi2`, `df`, `p_value` | num, int, num | Pearson chi-square test of group × attrition (no continuity correction) |
| `cramers_v` | num | Effect size, 0–1, comparable across variables |
| `significant` | bool | `p_value < 0.05` |
| `min_expected` | num | Smallest expected cell count (all ≥ 5 here, so the test is valid) |
| `levels` | array | One row per group, described below |

Each `levels[]` row: `level` (display label), `n`, `leavers`, `rate`, `ci_low` / `ci_high` (Wilson 95% interval for the rate), `lift` (rate ÷ company rate).

Level labels: tenure bands `0–1 yrs`, `2–4 yrs`, `5–9 yrs`, `10+ yrs`. Age bands `18–24` … `45–60`. Income quartiles `Q1 (1,009–2,911)` … `Q4 (8,380–19,999)` (real min–max inside each quartile, in the dataset's own units). Job level and stock option: `Level 1` … `Level 5` and `Level 0` … `Level 3`. Satisfaction: `1 Low` … `4 Very High`. Work-life balance: `1 Bad` … `4 Best`. Distance: `1–5`, `6–10`, `11–20`, `21–29`. Travel: `Non-travel`, `Travels rarely`, `Travels frequently`.

* `top_levels` (array, 10 items): the groups with the highest attrition across all variables, groups of 50+ only. Fields: `variable`, `key`, `level`, `n`, `leavers`, `rate`, `ci_low`, `ci_high`, `lift`.

## `logit`

Logistic regression, `glm(binomial)`.

| Field | Type | Meaning |
|---|---|---|
| `formula` | string | Model formula (16 predictors) |
| `fit_on` | string | Odds ratios come from the fit on all 1,470 employees; validation from the 70% training fit |
| `n`, `events` | int | Rows and leavers in the full fit |
| `aic` | num | AIC of the full fit |
| `pseudo_r2_mcfadden` | num | McFadden pseudo-R² |
| `odds_ratios` | array | Sorted by odds ratio, highest first |

Each `odds_ratios[]` row:

* `term`: model column name, e.g. `Overtime` or `EntryLevel`.
* `label`: plain English, e.g. "Works overtime (vs not)" or "Age, per +10 years".
* `odds_ratio`, `ci_low`, `ci_high`: 95% profile-likelihood interval. Values above 1 mean higher odds of leaving.
* `p_value`, `significant` (`p < 0.05`).

Terms: `Overtime`, `EntryLevel`, `LowJobInvolvement`, `PoorWorkLifeBalance`, `DeptSales`, `LowEnvironmentSatisfaction`, `NoStockOptions`, `FrequentTravel`, `LowJobSatisfaction`, `DeptHR`, `Distance10`, `Single`, `NumCompaniesWorked`, `YearsSinceLastPromotion`, `YearsAtCompany`, `Age10`.

## `survival`

"When do people leave?"

> **Read this first.** The file is a one-period snapshot, so leavers from earlier years are missing. The textbook Kaplan-Meier treats it as full history, which hides early exits: it gives 98.9% first-year retention, while 36% of first-year employees left. The primary curves below therefore use **delayed entry**. They assume the attrition window is one year: `Surv(start = YearsAtCompany, stop = YearsAtCompany + 1, event)`. Each curve is a synthetic cohort: the share of new hires still employed after *t* years if this year's exit rate at each tenure held. The textbook version is kept under `survival.naive`, for comparison only.

| Field | Type | Meaning |
|---|---|---|
| `method`, `assumption`, `time_definition` | string | Text versions of the note above |
| `min_risk_for_display` | int | 10. A step with fewer people at risk is "sparse" |
| `overall` | KM group | All employees |
| `by_overtime` | object | `logrank` plus `groups` (`No`, `Yes`) |
| `by_job_level` | object | `note`, `logrank` plus `groups` (`Level 1`, `Level 2`, `Level 3–5`). Levels 3–5 are pooled because levels 4 and 5 have 0–6 people in each early tenure year |
| `exit_rate_by_tenure` | object | Model-free exit rate in each tenure year: `overall`, `overtime_no`, `overtime_yes` |
| `cox` | object | Cox model with delayed entry |
| `naive` | object | Textbook KM, survdiff and Cox, for comparison only |

`logrank`: `method`, `chi2`, `df`, `p_value`. The primary views use the Cox score test on (start, stop] data, which is the log-rank test generalised to delayed entry. `survdiff` cannot handle delayed entry. The naive views use `survdiff`.

### KM group object

Used by `overall` and each entry in `groups`.

| Field | Type | Meaning |
|---|---|---|
| `group` | string | "All employees", "No", "Yes", "Level 1", … |
| `n`, `events` | int | People and leavers in the group |
| `median_years` | int or null | Median time to exit (KM). `null` if the curve never reaches 50% |
| `median_ci` | [num or null, num or null] | 95% interval of the median |
| `median_reliable` | bool | Every step up to the median had at least `min_risk_for_display` people at risk |
| `display_max_time` | int | Suggested x-axis limit: the last step (≤ 20) with enough people at risk. The report draws to 10 |
| `sparse_steps` | int[] | Steps up to `display_max_time` with fewer than 10 people at risk. Fade or dash them |
| `retention` | array, 4 | Values at years 1, 2, 5, 10 |
| `curve` | array | Step points (absent in `naive.by_*` groups) |

* `retention[]`: `year`, `surv` (share still employed after `year` years; `null` if not estimable), `lower`, `upper` (95% CI), `min_n_risk` (smallest risk set among the steps up to that year), `reliable` (`min_n_risk ≥ 10`). In this run every checkpoint for `Level 3–5` is unreliable: only 4 people at those levels were in their first year.
* `curve[]`: `time`, `surv`, `lower`, `upper`, `n_risk`, `n_event`. The first row is the anchor (time 0, surv 1). Draw it as a **step-after** line (`d3.curveStepAfter`): `surv` holds from `time` until the next point. Times are integer years since joining.

## `tree`

A regression tree (`rpart`, method "anova") on the 0/1 outcome, fit on all employees. Each leaf's mean is its attrition rate.

| Field | Type | Meaning |
|---|---|---|
| `method` | string | Description |
| `control` | object | `cp`, `minbucket`, `maxdepth` |
| `n_leaves` | int | 6 |
| `leaves` | array | Sorted by rate, highest first |
| `variable_importance` | array | `variable`, `label`, `importance` (sums to 100) |
| `cp_table` | array | `cp`, `nsplit`, `rel_error`, `xerror` (10-fold cross-validated) |

Each `leaves[]` row:

* `node`: rpart node id.
* `rule`: for example "Overtime = Yes & Monthly income < 2,475".
* `rule_text`: the rule plus its outcome, e.g. "… → 70% leave (n = 69)".
* `conditions`: string[], one readable condition per variable.
* `n`, `leavers`, `rate`, `lift` (vs company rate).
* `share_of_employees`, `share_of_leavers`.

## `whatif`

Expected leavers if overtime were removed for a share of overtime workers. This is an associational model, not a causal claim.

| Field | Type | Meaning |
|---|---|---|
| `model` | string | Full-data logistic regression; the counterfactual sets Overtime = 0 and changes nothing else |
| `observed_leavers` | int | 237 |
| `base_expected_leavers` | num | Sum of predicted probabilities. It equals the observed leavers, a property of logistic regression |
| `overtime_workers`, `overtime_leavers` | int | 416 / 127 |
| `total_risk_reduction_all_ot` | num | Σ(p_now − p_no_ot) over all overtime workers: expected leavers avoided if nobody worked overtime |
| `naive_reduction_rate_gap` | num | overtime_workers × (overtime rate − no-overtime rate), for context |
| `scenarios` | array, 5 | One row per share s = 0, 0.25, 0.5, 0.75, 1 |
| `employees` | object | Columnar arrays, one entry per overtime worker |
| `cost_inputs` | object | Pay figures for a user-chosen replacement-cost assumption |

* `scenarios[]`: `share`, `workers_moved`, `expected_leavers_random`, `expected_leavers_targeted`, `reduction_random`, `reduction_targeted`, `attrition_rate_random`, `attrition_rate_targeted`. "Random" picks the share at random. "Targeted" moves first the workers whose predicted risk drops most.
* `employees` has `note` plus parallel arrays, each 416 long, sorted by `p_now − p_no_ot` with the largest drop first:
  * `emp_no`: EmployeeNumber.
  * `p_now`: predicted probability of leaving today.
  * `p_no_ot`: the same person's prediction with Overtime = No.
  * `monthly_income`, `job_level`, `department`.
  * `left`: 1 if the person actually left.
* `cost_inputs`:
  * `avg_monthly_income_leavers`, `median_monthly_income_leavers`, `avg_monthly_income_all`, `avg_monthly_income_ot_leavers`.
  * `avg_monthly_income_avoided`: income of the avoided exits, weighted by each person's drop in risk.
  * `note`. Income is in the dataset's own units. No cost figure is asserted.

**Formulas for the UI** (any share `s` between 0 and 1; `d[i] = p_now[i] − p_no_ot[i]`):

* Random: `expected = base_expected_leavers − s × total_risk_reduction_all_ot`
* Targeted: `k = round(s × overtime_workers)`; `expected = base_expected_leavers − (d[0] + … + d[k−1])`. The arrays are already sorted.
* Cost avoided, with a user-chosen multiple `m` of annual pay: `Σ d[i] × monthly_income[i] × 12 × m` over the moved workers. As a shortcut, use `reduction × avg_monthly_income_avoided × 12 × m` for the "all" case, or `avg_monthly_income_leavers` for a simpler story.

## `caveats`

`string[]`, six items: fictional data; observational, not causal; the one-year window and synthetic-cohort reading of the survival curves; small hold-out set; stock options and marital status are entangled; protected traits are controls only.
